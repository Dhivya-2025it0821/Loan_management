# Northstar Lending - Loan Management System

Frontend-only mini project for a loan management system, built with HTML, CSS, and vanilla JavaScript.

## Run

Open `index.html` directly in a browser, or serve this folder locally:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Included

- Responsive admin dashboard with portfolio metrics and charts
- Customer directory with search and add-customer modal
- Loan application queue with application form and EMI preview
- Active loan and EMI payment tables
- Payment recording modal and CSV exports
- Reports and settings views
- Demo data persisted in browser `localStorage`

This version intentionally uses mock data and browser storage. PHP, MySQL, authentication, and server-side validation can be connected later using the tables and relationships from the supplied development guide.
